# ⚔ ラストウォーデン ―終焉世界記―

たった一人のウォーデン（守護戦士）として、侵蝕された世界を救う本格3D RPGです。
四体の守護霊の成れの果てと戦い抜き、すべての元凶「デスタイタン」に挑む、全4章の物語。
ブラウザで `index.html` を開くだけで遊べます（インストール不要・ログイン不要・単一HTMLファイル）。

## 遊び方

1. `index.html` をブラウザで開く
2. タイトル画面で「物語を始める」を押す
3. 各章の冒頭でストーリーを読み、「たたかう」でバトル開始
4. 章をクリアすると経験値でレベルアップし、次の章のストーリーへ

## ストーリー

かつて四体の守護霊に護られていた世界ヴェルディア。「ヴォイドファーザー」と呼ばれる深淵の
存在が守護霊たちを侵蝕し、世界は静かに終わりへ向かっている。最後の一人となった戦士＝
ウォーデンは、穢された守護霊たちを解放しながら、すべての元凶へと近づいていく――。

| 章 | 敵 | 概要 |
|---|---|---|
| 第1章 | モスシェイド | 苔纏いの森の番人 |
| 第2章 | ドレッドノート | 鉄鎖に縛られた亡霊騎士 |
| 第3章 | アビス | 深淵で歌い続ける詠唱者 |
| 第4章 | デスタイタン | すべての元凶、終焉の巨神（覚醒フェーズあり） |

## 特徴

- **本格RPGのストーリー進行**: 全4章、章ごとの物語＋レベルアップ＋敵の個性豊かなビジュアルと攻撃パターン
- **実写級の3Dグラフィック**: リギング済みglTF人体モデルとPBR（物理ベース）レンダリングにより、プレイヤーも敵も高品質な質感で描画
- **戦略的なバトルシステム**: 通常攻撃・強攻撃・必殺技（MP消費）・防御・回復を駆使して戦う
- **コンボシステム**: 連続攻撃でダメージ倍率が上昇
- **QTE回避**: 敵の攻撃を予告表示後、タイミングよくクリックすれば完全回避
- **ボス覚醒フェーズ**: 最終章デスタイタンはHPが半分を切ると覚醒し、攻撃パターンが激化
- **演出**: ヒットパーティクル、フローティングダメージ数値、画面シェイク、環境光による反射、WebAudioによる効果音
- **リザルト評価**: 被ダメージ量とターン数に応じてS〜Cランクを判定
- **モバイル完全対応**: iPhoneなどのスマホでも大きく見やすいUIで快適プレイ
- **オフライン動作**: Three.jsおよび3Dモデルをすべてインライン化しているため、外部通信なしで動作

## 技術構成

- [Three.js](https://threejs.org/)（r152）によるWebGL 3Dレンダリング
- glTFモデル・ライブラリ一式をBase64でHTMLに埋め込み、単一ファイルで完結
- 効果音はWeb Audio APIでリアルタイム生成（外部音源ファイル不要）
